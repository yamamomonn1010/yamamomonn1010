## 制作物

### manaba課題リマインダー Discord Bot｜制作中

大学の課題の見落としを減らすために、manabaから課題を取得し、Discordに通知するBotを制作しています。
Pythonを使い、SQLiteでのデータ管理やDiscordとの連携に取り組んでいます。

[コード・機能・設計の詳細を見る →](https://github.com/yamamomonn1010/manaba-reminder-bot)

### 歩きスマホ検知アプリ｜大学演習

スマートフォンのセンサーデータから、歩行中の状態を分類するシステムを制作しました。
加速度・ジャイロセンサーのデータを使い、scikit-learnのランダムフォレストで分類しました。

使用技術：Python / scikit-learn / Streamlit
